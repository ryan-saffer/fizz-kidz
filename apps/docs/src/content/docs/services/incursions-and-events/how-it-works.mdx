title: How incursions and events work
description: How incursions and events are created, edited and confirmed in the Portal.

Incursions and standard events are created and managed in the Portal. Open **Bookings**, then choose **New Booking** >
**Event**. Existing bookings appear on the **Incursions** and **Parties & Events** tabs.

## Creating an event

<Steps>
  <ol>
    <li>
      <h3>Enter the booking details</h3>
      <p>
        Add the event and organisation, contact details, studio, address, price, notes, invoice link, and event type.
        Incursions also include their module and expected students per session.
      </p>
    </li>
    <li>
      <h3>Add one or more time slots</h3>
      <p>
        Add every session now. Slots can only be added while creating the booking. All slots share the booking details,
        and each has its own start and end time.
      </p>
    </li>
    <li>
      <h3>The calendar and Zoho are updated</h3>
      <p>
        Each slot appears on the Events calendar, including incursions. The linked Zoho deal is confirmed or created
        with the booking details and all session times.
      </p>
    </li>
    <li>
      <h3>The customer receives a confirmation</h3>
      <p>
        <strong>Send confirmation email</strong> is on by default and needs an email message. The confirmation lists all
        slots, the address, price, and your message. Incursion confirmations also name the chosen module.
      </p>
    </li>
  </ol>
</Steps>

<Aside type="note" title="Type and studio are locked">
  The event type and studio can't be changed after the booking is created, so check them before saving.
</Aside>

## What edits change

Edits and deletes do not email the customer.

<CardGrid>
  <Card title="Shared details" icon="puzzle">
    Editing one slot updates the shared details, such as contact, organisation, address, price, and notes, on every slot
    and on the Events calendar.
  </Card>
  <Card title="Slot times" icon="clock">
    The start and end time you edit apply to that slot only. Other slots keep their dates and times.
  </Card>
  <Card title="Linked Zoho deal" icon="rocket">
    Editing a booking updates the deal with all current slots.
  </Card>
  <Card title="Deleting a slot" icon="warning">
    Deleting removes that slot from the Portal and the Events calendar and updates the session times on the Zoho deal.
  </Card>
</CardGrid>

For final incursion details, see [Preparation forms](/services/incursions-and-events/preparation-forms/). For calendar
access, see [Calendars](/tools/calendars/).
