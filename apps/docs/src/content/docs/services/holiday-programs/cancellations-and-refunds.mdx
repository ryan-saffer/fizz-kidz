---
title: Cancellations and rescheduling
description: How customers change Holiday Program sessions in the Portal and when a refund applies.
---

import { Aside, Badge, Card, CardGrid, LinkCard } from '@astrojs/starlight/components'

Each booking confirmation has a <strong>Change / Cancel</strong> link beside every child/session. It opens that
appointment in the Portal, with the session details and options to cancel or reschedule. No login is needed.

## The 48-hour rule

<CardGrid>
  <Card title="At least 48 hours before" icon="approve-check-circle">
    <Badge text="Automatic" variant="tip" size="small" />
    <br />
    Customers can reschedule or cancel. Cancelling automatically refunds the amount paid for that child and session.
  </Card>
  <Card title="Inside 48 hours" icon="warning">
    <Badge text="No automatic refund" variant="caution" size="small" />
    <br />
    Rescheduling is disabled with an explanation. Customers can still cancel before the session starts and receive a
    cancellation email, but no refund is created.
  </Card>
  <Card title="Free line" icon="information">
    A fully discounted appointment can be cancelled, but there is no paid amount to return.
  </Card>
  <Card title="Gift card + card" icon="seti:lock">
    A split payment is refunded to the original gift card and card, up to the amount paid with each.
  </Card>
</CardGrid>

<Aside type="note" title="Choosing another session">
  Rescheduling moves one child's appointment to another available holiday-program session at the same studio. The
  current session must be at least 48 hours away, but the replacement can start sooner. The payment carries over and the
  customer receives an updated confirmation email.
</Aside>

Customer changes close when the session starts. For a full-day booking, the morning and afternoon are separate
appointments, so customers manage each one using its own link. Links in older confirmations may still open Acuity.

<Aside type="tip" title="What the customer receives">
  Every cancellation sends a cancellation email with the session details and policy. It includes a refund receipt link
  when available. Each <strong>Change / Cancel</strong> link applies to one child and session.
</Aside>
