The **Reports** page uses the studio selected at the top right of the Portal. It is available to admins when a
franchise studio or the master organisation is selected.

<Aside type="note" title="Check the selected studio first">
  A report can be accurate and still answer the wrong question if a different studio or the master organisation is
  selected.
</Aside>

## Holiday Program Capacity

This report shows upcoming classes, booked children, total capacity, remaining spots, and utilisation. Confirm the
selected studio and the **Updated** time. Use **Refresh** for a new snapshot. Master access can switch between studio and
daily breakdowns.

Turn on **Compare with previous period** to see whether bookings are ahead of, behind, or level with the previous
holiday program at the same number of days before it opened.

## Party Capacity Utilisation

This report shows how full the studio's party slots are: its **in-studio** birthday party bookings compared with the
party slots available on those dates. The available slots are already set for each date, so there's nothing to enter.

<Steps>
  <ol>
    <li>
      Choose a <strong>Date range</strong>: the current or upcoming month, the next 30 or 90 days, until the end of the
      year, or a custom range.
    </li>
    <li>
      Read <strong>Capacity reached</strong> together with the number of in-studio bookings and available slots.
    </li>
    <li>Check the weekly breakdown to see which weeks are filling up.</li>
  </ol>
</Steps>

The report updates as soon as you change the dates. With the master organisation selected, choose **Studio breakdown**
or **Weekly breakdown** to compare studios. Mobile parties are not included.

<Aside type="note" title="Available dates">
  Party slots are set from 3 July to 31 December 2026, so choose dates within that period.
</Aside>
